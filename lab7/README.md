| `book-store/` | Angular client (the Lab 4 Book Store, updated to use the REST API) |

## Exercise

An **Authors** option was added to the navigation bar. It shows a form where the user enters an author id.
On submit, the app queries `GET /books-api/authors/{id}` and displays the author's information:
first name, last name, biography, and the books written by the author. The biography and the books are
loaded by following the `bio` and `books` hyperlinks of the author representation.

- If no author has this id (HTTP 404), the message *"Sorry, no author was found with id X"* is displayed.
- If the id is not a positive whole number, a validation message is displayed and no request is sent.
- If the API cannot be reached, an error message is displayed.

Main files of the exercise (in `book-store/src/app/`):

- `app.html`, `app.routes.ts` – the Authors menu option and the `/authors` and `/authors/:id` routes
- `authors/authors.ts|html` – the search form (reactive form with validation)
- `authors/author/author.ts|html` – displays the author, or the "not found" / error message
- `authors/service/authors-service.ts` – calls the API and follows the HATEOAS links
- `authors/model/author-details.ts` – types of the API responses

## Requirements

- JDK 21
- Docker (for MySQL)
- Node.js 22 or later and npm

## How to run

### 1. Start MySQL

```bash
docker run -d -p 6033:3306 --name=docker-mysql --env="MYSQL_ROOT_PASSWORD=root" --env="MYSQL_PASSWORD=root" --env="MYSQL_DATABASE=booksDb" mysql
```

If the container already exists, start it with `docker start docker-mysql`.

### 2. Start the REST API (port 8080)

```bash
cd books-rest-api
./gradlew bootRun
```

When the database is empty, `DataLoader` inserts sample data on startup:

| Author id | Name | Books |
|---|---|---|
| 1 | Koredo Tablanga | SpringBoot JPA and REST, Introduction to Angular |
| 2 | Jane C | A Fantastic Story |

The ids are generated by the database, so they may differ if data was added before.
`GET http://localhost:8080/books-api/authors` lists all authors with their ids.

- API base URL: http://localhost:8080/books-api
- Swagger UI: http://localhost:8080/swagger-ui.html

### 3. Start the Angular client (port 4200)

In another terminal:

```bash
cd book-store
npm install
npx ng serve
```

Open http://localhost:4200, click **Authors**, and search for an id such as `1` (found) or `99` (not found).

The Admin page (login `admin` / `password`) adds new books and authors through the API.

### Tests

```bash
cd book-store
npx ng test --watch=false
```

## Main API endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/books`, `/books/{id}` | All books, one book |
| POST / PUT / DELETE | `/books`, `/books/{id}` | Add, update, remove a book |
| GET / POST | `/books/{id}/authors` | Authors of a book, add a new author to a book |
| PATCH | `/books/{bookId}/authors/{authorId}` | Add an existing author to a book |
| GET / POST | `/books/{id}/orders` | Orders of a book, add an order |
| GET | `/authors`, `/authors?firstName=&lastName=` | All authors, authors with a given name |
| GET / PUT / DELETE | `/authors/{id}` | One author |
| GET | `/authors/{id}/books` | Books of an author |
| GET / PUT | `/authors/{id}/bio` | Biography of an author |
